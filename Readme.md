# TodoAI

A chat-based task manager.

## Quick Start

1. Clone the repo:
   ```bash
   git clone https://github.com/sridhar-mani/TodoAI.git
   cd TodoAI
   ```

2. Run the backend:
   ```bash
   cd backend
   pip install -r requirements.txt
   uvicorn app:app --reload
   ```

3. Run the frontend:
   ```bash
   cd frontend
   pnpm install
   pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) and chat to manage your tasks.

## How to Use

- Type commands like:
  - Create a task: "Buy groceries tomorrow"
  - List tasks: "Show my tasks"
  - Update a task: "Mark task #3 as done"
  - Delete a task: "Remove task about calling bank"
